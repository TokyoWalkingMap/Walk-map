鉄筋コンクリート設計ラボ

コンクリートは押されると強く、引っ張られると弱い材料です。引張強さは圧縮強さの約10分の1しかありません。そこで、引っ張られる側にだけ鉄筋を入れて引張を受け持たせるのが鉄筋コンクリート（RC）です。梁を実際に壊してみてから、擁壁と橋の床版を、実務と同じ手順で設計します。

1 梁を壊す・設計する2 擁壁3 橋の床版導き方実例と街で探す

謎1 予想してから、下の梁で確かめる

梁に入れる鉄筋を増やしていくと、梁はどうなるでしょう。

鉄筋を入れすぎると、鉄筋が伸び切る（降伏する）前に、上側のコンクリートが先に潰れます。コンクリートの圧壊は前触れなく一瞬で起きるので、強さは上がっても壊れ方は危険になります。下の梁で「鉄筋ぎっしり」を押して、M–φ曲線の終わり方を比べてください。普通の梁は鉄筋が先に伸びて大きくたわみ、壊れる前に「危ない」と目で分かります。設計では鉄筋比 ρ をつり合い鉄筋比 ρb の75％以下に抑えて、必ずこちらの壊れ方にします。

梁を壊してみる 荷重を上げると、ひび割れ → 鉄筋降伏 → 圧壊

謎2 擁壁の鉄筋はどちら側？

道路わきで土を支える逆T形の擁壁。壁の中の主な鉄筋（縦の太い鉄筋）は、壁のどちら側に寄せて入れるでしょう。

土側です。土は壁を道路側へ押し出そうとするので、壁は根元を固定された片持ち梁のように道路側へ曲げられます。このとき引っ張られるのは土に接している面です。だから鉄筋は見えない土側に寄せて入れ、底版の中まで曲げ込んで定着させます。見えている道路側の鉄筋は、乾燥や温度でひび割れないための細い鉄筋です。下の設計で鉄筋を道路側にすると、何が起きるか確かめられます。

謎3 橋の床が抜けた

昭和40年代から50年代にかけて、交通量の多い道路橋で、鉄筋コンクリートの床版に亀の甲羅のようなひび割れが広がり、最後は穴が開いて抜け落ちる事故が相次ぎました。いちばん大きな原因は何だったでしょう。

繰り返しの力による疲労です。1回なら耐えられる重さでも、何百万回も繰り返すとひび割れが少しずつ伸び、縦横に格子状につながって亀甲状になり、最後は押し抜かれます。当時の床版は薄く、配力鉄筋（橋の長さ方向の鉄筋）も少なかったうえ、大型車が想定以上に増えました。そこで基準が改められ、床版の最小厚さを支間と大型車の交通量で決め、鉄筋の許容応力度をわざと低め（140 N/mm²）にして、繰り返しに余裕を持たせるようになりました。下の設計の「最小厚さ」と「140」がその名残です。

導き方 上で使った式は全部ここから出てくる

① なぜ鉄筋とコンクリートは一緒に働けるのか
1

コンクリートは圧縮に強く（24 N/mm² なら1 cm²で約240 kg を支える）、引張はその約1/10。鉄筋は引張に強いが、細いので圧縮では座屈しやすい。弱点が逆なので、組み合わせると互いの弱点を消せます。

2

一緒に動くには、境目でずれないこと（付着）が必要です。異形棒鋼の表面の節がコンクリートに噛み込み、鉄筋とまわりのコンクリートが同じだけ伸び縮みします。これが次の「平面保持」の前提です。

3

温度が変わっても離れないこと。熱膨張係数は、コンクリートも鉄筋もほぼ 10×10⁻⁶ /℃ で同じです。さらにコンクリートは強いアルカリ性で、中の鉄筋の表面に薄い膜を作り、錆を防ぎます。

② 平面保持：ひずみは高さ方向に直線になる
1

曲げられる前に平らだった断面は、曲げられた後も平らなまま回転する、と考えます（ベルヌーイ・ナビエの仮定）。梁の実験で確かめられている仮定です。

2

断面が角度だけ回るので、伸び縮みは中立軸からの距離に比例します。曲率を φ、中立軸の深さを x、上端からの深さを y とすると

ε(y) = φ·(x − y)　　上端 ε′c = φ·x、　鉄筋 εs = φ·(d − x) = ε′c·(d − x)/x
3

付着があるので、鉄筋のひずみは同じ高さのコンクリートのひずみと等しい。上の「梁を壊してみる」の断面図の青い三角形がこれです。応力はひずみに材料の性質（応力–ひずみ関係）を当てはめて決まります。

③ 中立軸 k = −nρ + √((nρ)² + 2nρ)（許容応力度法）
1

使っている時（荷重が小さい時）は、コンクリートも鉄筋も弾性として扱います。引張側のコンクリートはひび割れているので無視します。鉄筋はコンクリートの n = Es/Ec 倍硬いので、面積を n 倍したコンクリートに置き換えられます（換算断面、道路橋示方書では n = 15）。

2

中立軸は換算断面の図心を通ります。中立軸まわりの断面一次モーメントが0になる条件から

b·x·(x/2) = n·As·(d − x)
3

x = kd、As = ρbd を入れて b·d² で割ると、k の2次方程式になります。

k²/2 = nρ(1 − k)　→　k² + 2nρ·k − 2nρ = 0　→　k = −nρ + √((nρ)² + 2nρ)
4

鉄筋が多い（ρ が大きい）ほど k が大きくなり、中立軸が下がります。鉄筋が引張をよく受け持てるぶん、圧縮側も広く必要になるからです。

④ σc = 2M/(k·j·b·d²)、σs = M/(As·j·d)
1

圧縮側の応力は三角形なので、圧縮力の合計は C = ½·σc·b·x。作用点は上から x/3 です。

2

引張は鉄筋だけで T = As·σs。C と T の距離（腕の長さ）は jd = d − x/3、つまり j = 1 − k/3。

3

C = T で、この組（偶力）が曲げモーメント M に釣り合います。

M = C·jd = ½·σc·b·kd·jd　→　σc = 2M/(k·j·b·d²)
M = T·jd = As·σs·jd　→　σs = M/(As·j·d)
4

これを許容応力度（コンクリート σck/3、鉄筋 180、床版の鉄筋 140 N/mm²）以下にするのが許容応力度法です。ミッション2・3の計算はこの式です。

⑤ ひび割れモーメント Mcr = ft·b·h²/6
1

ひび割れる前は、引張側のコンクリートも効いています。鉄筋の影響を無視すると、ただの長方形断面の弾性の曲げです。

2

下端の引張応力は σ = M/Z、断面係数 Z = b·h²/6。これがコンクリートの引張強度 ft（標準示方書の目安 ft = 0.23·f′ck^(2/3)）に達したらひび割れます。

Mcr = ft·b·h²/6　（b=300, h=600, f′ck=24 なら ft = 1.92 N/mm²、Mcr ≈ 35 kN·m）
3

普通の梁では、使っている時の荷重でもうひび割れています。ひび割れは失敗ではなく、引張を鉄筋に渡した合図です。問題になるのは幅が大きすぎるひび割れで、そこから水や塩分が入って鉄筋が錆びます。

⑥ 等価応力ブロックと曲げ耐力 Mu = As·fy·(d − a/2)
1

壊れる時、上端のコンクリートは終局ひずみ ε′cu = 0.0035 に達し、圧縮応力は放物線＋水平の形になります。この形を、合力の大きさと位置が同じ長方形（高さ k₁·f′c、深さ a = β·x、標準示方書では f′ck ≤ 50 で k₁ = 0.85、β = 0.8）に置き換えます。

2

普通の梁では鉄筋はもう降伏しているので T = As·fy。C = T から a が決まります。

k₁·f′c·b·a = As·fy　→　a = As·fy/(k₁·f′c·b)
3

圧縮の合力は長方形の真ん中（上から a/2）に働くので、腕の長さは d − a/2。

Mu = T·(d − a/2) = As·fy·(d − a/2)
4

設計では材料の強さを安全係数で割り（f′cd = f′ck/1.3、fyd = fy/1.0）、さらに部材係数 γb = 1.1 で割った Mud を、荷重に係数をかけた Md 以上にします（ミッション1）。上の「梁を壊してみる」の Mu（繊維で細かく計算した値）と、この手計算の値はほぼ一致します。

⑦ つり合い鉄筋比 ρb：どこから脆くなるか
1

鉄筋の降伏（εs = εy = fy/Es）と上端の圧壊（ε′c = ε′cu）が同時に起きる鉄筋量を「つり合い」と呼びます。ひずみは直線なので

xb/d = ε′cu/(ε′cu + εy)　（SD345なら εy = 345/200000 = 0.001725、xb = 0.67d）
2

その時の C = T に a = β·xb を入れると

k₁·f′c·b·β·xb = ρb·b·d·fy　→　ρb = k₁·β·(f′c/fy)·ε′cu/(ε′cu + εy)
3

ρ が ρb より多いと、鉄筋が伸び切る前にコンクリートが潰れます（謎1の答え）。ばらつきに余裕を持って ρ ≤ 0.75ρb とし、少なすぎてもひび割れと同時に壊れるので ρ ≥ 0.2% とします。

⑧ 主働土圧係数 Ka = tan²(45° − φ/2)（ランキン）
1

土の中の深さ z の点には、上の土の重さで鉛直応力 σv = γ·z がかかります。壁が少し前に動くと、水平応力 σh は下がっていき、土がせん断で崩れる寸前（主働状態）で止まります。

2

崩れる寸前は、モールの応力円が破壊線 τ = σ·tanφ（砂、粘着力なし）に接します。円の中心 (σv + σh)/2、半径 (σv − σh)/2 から

sinφ = (σv − σh)/(σv + σh)　→　σh/σv = (1 − sinφ)/(1 + sinφ) = tan²(45° − φ/2) = Ka
3

φ = 30° なら Ka = 1/3。水平の土圧は深さに比例する三角形 Ka·γ·z になり、上載荷重 q は一様に Ka·q を足します。詳しい導出は地盤の理論ラボにあります。

⑨ 擁壁の壁の根元の曲げ M = Ka·γ·h′³/6 + Ka·q·h′²/2
1

壁は底版に固定された片持ち梁です。高さ h′ の壁に、三角形の土圧（下端で Ka·γ·h′）と長方形の上載土圧（Ka·q）がかかります。

2

三角形の合力は ½·Ka·γ·h′²、作用点は根元から h′/3。長方形は Ka·q·h′、作用点は h′/2。根元まわりのモーメントは力×距離の和です。

M = ½·Ka·γ·h′²·(h′/3) + Ka·q·h′·(h′/2) = Ka·γ·h′³/6 + Ka·q·h′²/2
3

h′ の3乗で効くので、高さが2倍になると曲げは約8倍。高い擁壁ほど根元が急に厚く、鉄筋が太くなるのはこのためです。引っ張られるのは土側の面です（謎2）。

⑩ 転倒・滑動・支持力の3つの照査
1

転倒：つま先まわりで、重さが戻すモーメント Mr と土圧が倒すモーメント Mo を比べ、合力の位置 x = (Mr − Mo)/V を出します。底版の中心からのずれ e = B/2 − x が B/6 以下なら、合力は底版の真ん中1/3に入り、底面全体が地盤を押します（浮き上がらない）。

2

滑動：底面の摩擦力 μ·V が、土圧の横の力 Ph の1.5倍以上あること。

Fs = μ·V/Ph ≥ 1.5
3

支持力：鉛直力 V と、ずれ e によるモーメント V·e を、幅 B の底面で受けます。長方形の断面の「軸力＋曲げ」と同じ形です。

q = V/B ± V·e/(B²/6) = V/B·(1 ± 6e/B) ≤ qa
4

この3つは地盤との勝負、壁の鉄筋は RC としての勝負です。B を広げると地盤は楽になり、t と鉄筋で壁を強くします。両方を満たして安い組み合わせを探すのが設計です。

⑪ 床版の曲げモーメント (0.12L + 0.07)P と最小厚さ k₁(30L + 110)
1

床版は4辺を支えられた板で、1つのタイヤ（T荷重 P = 100 kN、接地面 500 mm × 200 mm）が載ります。板の理論で、タイヤをいろいろな位置に置いて最大の曲げを求め、支間 L の直線式にまとめたのが道路橋示方書の式です。衝撃の分も含まれています。

単純版の主鉄筋方向　M = (0.12L + 0.07)·P　［kN·m/m、L は m、0 < L ≤ 4］
2

桁が何本も並ぶ連続版では、隣の支間が回転を押さえるので、支間の曲げも支点の曲げも単純版の8割とします。床版自身と舗装の重さ w による曲げ w·L²/10 を足します。

3

最小厚さは、謎3の事故の反省から決まった経験式です。30L + 110 mm を基本に、大型車の交通量が多いほど係数 k₁（1.10〜1.25）で厚くします。強さの計算で足りても、薄い床版は繰り返しで抜けるからです。

⑫ 二つの設計法：許容応力度法と限界状態設計法
1

許容応力度法：普段の荷重で、応力が「強さ÷安全率」（許容応力度）以下かを見ます。計算は簡単ですが、壊れるまでの余裕がどれだけあるかは直接には分かりません。ミッション2・3の方法です。

2

限界状態設計法：「壊れる」「使えなくなる（ひび割れ・たわみ）」「疲労で壊れる」などの状態ごとに、荷重を大きめに、強さを小さめに見積もって比べます。ミッション1の方法で、今の土木学会の示方書と道路橋示方書はこの考え方です。

3

どちらも同じ力のつり合い（C = T、M = T × 腕の長さ）から出発しています。違うのは、どの状態で比べるかと、安全の余裕をどこに入れるかです。

実例と使い道

日本で最初の鉄筋コンクリート橋（1903年）

京都の琵琶湖疏水に架かる日ノ岡第11号橋は、田辺朔郎の指導で造られた日本初の鉄筋コンクリート橋とされます。長さ約7 mの小さな橋で、今も山科の疏水沿いで見られます。

首都高・阪神高速の床版取替

疲労で傷んだRC床版は、鋼板を下面に貼る、上面を厚くする、工場で作ったプレキャストPC床版に丸ごと取り替える、という順で対策されてきました。夜間に通行止めをして、一晩で何枚も入れ替える工事が今も続いています。

宅地の擁壁と水抜き孔

擁壁が倒れる事故の多くは、背面に雨水がたまり、土圧に水圧が加わることが引き金です。宅地造成の基準では、壁面3 m²ごとに内径7.5 cm以上の水抜き孔を設けるよう定めています。上の設計は水圧がない前提なので、水抜き孔が詰まると前提が崩れます。

かぶりと鉄筋のさび

鉄筋はアルカリ性のコンクリートに守られて錆びませんが、表面から中性化や塩分が進むと錆び、膨らんで表面を割ります（爆裂）。鉄筋の外側のコンクリートの厚さ（かぶり）を守ることが、強さと同じくらい大事です。

街で探そう

  • 擁壁の表面に並ぶ丸い穴（水抜き孔）。壁の高さと穴の数を数えてみる。
  • 高架下から床版の裏を見上げる。格子状に貼られた鋼板や炭素繊維シートは、疲労対策の跡。
  • 古いコンクリートの角が割れて、錆びた鉄筋が見えている所。鉄筋が外側からどれだけの深さにあるかが、かぶり。
