1謎：ダムの水は、いつ一番多い？

謎

大雨でダムに流れこむ水が増え、ピークを過ぎてだんだん減っていく。ダムは一定の量だけ放流している。ダムにたまっている水がいちばん多くなるのは、いつ？

ピークを過ぎても、流れこむ量が放流より多いあいだは、水は増え続けます。増えるのが止まるのは「流れこむ量＝放流量」のとき。たまっている量（合計）は積分、増える速さ（流入−放流）は微分で、「速さが 0 のとき、量が最大」。3章の「貯水池」で確かめてみましょう。

2見分け方はひとつだけ

微分（ばらす）積分（集める）
知りたいこと変わる速さ、傾き、「1あたり」全部でいくら、たまった量、面積・体積
問題文のことば〜の速さ、〜の勾配、毎秒・毎時、密度、強さ合計、累計、総量、全部で、〜までに
グラフでは曲線の接線の傾き曲線の下の面積
単位は÷ 時間、÷ 長さ（m³ → m³/s）× 時間、× 長さ（m³/s → m³）
例沈下量 → 沈下の速さ、標高 → 川の勾配流量 → 貯水量、水圧 → 全水圧
「速さ・傾き・1あたり」は微分、「合計・たまった量・面積」は積分。単位を見ると、どちらかがすぐわかる。

そして、微分と積分は逆の操作です（微分積分学の基本定理）。量を微分すると速さ、速さを積分すると量に戻ります。下の図では、上のグラフの傾きが、下のグラフの高さと、いつも同じになっています。

4最大を探す ＝ 微分が 0

山のてっぺんでは、上りでも下りでもないので、傾きは 0 です。だから「いちばん大きい所」「いちばん小さい所」は、微分して 0 になる所を探せば見つかります。土木では、これがいちばんよく使う微分の使い方です。

例：梁のどこが、いちばん曲がろうとする？

長さ L＝10 m の単純梁に、w＝10 kN/m の荷重が一様にのる。曲げモーメントは M(x)＝50x − 5x²（kN·m）。

  1. 微分すると dM/dx＝50 − 10x。これはせん断力 Q そのもの（構造力学の dM/dx＝Q）。
  2. 50 − 10x＝0 より x＝5 m（真ん中）。
  3. M(5)＝250 − 125＝125 kN·m。これが最大で、公式 wL²/8＝10×100/8＝125 と一致。

3章の「梁」で、せん断力が 0 になる所で曲げが最大になるのを確かめられます。

道路の縦断（坂の上り下り）をつくるとき、峠のてっぺんの位置を知りたい。標高の式 z(x) があるとき、何をすればよい？

微分は「勾配」。てっぺんでは勾配 0 なので、dz/dx＝0 の所が峠の頂上です。道路では、勾配が急に変わる所を緩い曲線（縦断曲線）でつなぎ、その曲線の式の微分から頂上や見通しを計算します。

地盤力学：時間と深さの微分

粘土から水が抜ける速さを、時間と深さの両方で微分して書くと圧密方程式（偏微分方程式）。沈下量はそれを積分して出す。

振動：微分が2回

位置を微分すると速度、もう一度で加速度。m x″＋c x′＋k x＝F は微分方程式。地震計の加速度記録を2回積分すると、地面の動いた距離になる。

測量・土工：積分で土の量

道路をつくるとき、削る土と盛る土の量は、断面積を道路の長さ方向に積分（足し算）して出す。平均断面法はその近似。
